# CoZzee Restaurant Web Application

A responsive restaurant menu web application developed using Angular and TypeScript.

## Features
- Home page
- Interactive menu section
- Food categories
  - Starters
  - Main Course
  - Desserts
- Contact page
- Angular routing
- Responsive UI design

## Technologies Used
- Angular
- TypeScript
- HTML
- CSS

## Installation

```bash
npm install
ng serve
```

## Project Structure

```text
src/
 ├── app/
 │   ├── navbar/
 │   ├── pages/
 │   ├── categories/
 │   └── contact/
```
