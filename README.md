# Responsive Angular Web Application

A responsive multi-page web application developed using Angular and TypeScript.

## Features
- Responsive navigation bar
- Category sections
- Contact page
- Reusable Angular components
- Modern UI design

## Technologies Used
- Angular
- TypeScript
- HTML
- CSS

## Installation

```bash
npm install
ng serve
```

## Project Structure

```text
src/
 ├── app/
 │   ├── navbar/
 │   ├── categories/
 │   ├── contact/
 │   └── pages/
```
